# DSD 插件实现与验收

2026-10-23，按 `rebuild/docs/AUDIO_PLUGIN_DEVELOPMENT_GUIDE.md` 创建独立项目。

## 数据路径和接口

沿用原版 AddIn / Reader / Metadata / Thumbnail ABI，ordinal 1 导出，不修改任何旧虚表。Probe/SourceInfo 为独立可选接口；DSF、DSDIFF 分别报告 `.dsf`、`.dff`，不因 PCM 输出建议改名为 WAV。

DSF/DSDIFF → DSD 或 DST 解码 → FIR 重采样 → 176.4 kHz（44.1 系列）或 192 kHz（48 系列）PCM → 宿主均衡器/回放增益/输出链。Open 的浮点标志控制 float64，否则提供 PCM24。DSD 本身位深报告为 1，PCM 输出位深通过 Format 单独报告。

DSF 按头部声明样本数裁剪，避免最后一个 4096 字节分声道块的填充被当作音频；解码输入帧数单独核对，输出重采样帧数按最近整数取整。DSD256 的分数尾帧不可用向上取整后误判为截断。文件声明长度和实际长度不符、I/O 失败均返回错误。

保持标准 WAVE 声道顺序和掩码。无法确定的自定义 DSDIFF 声道顺序返回不支持，不猜测映射。2026.10.23p1 为可定位的普通 DSF／未压缩 DSDIFF 增加按数据偏移计算的定位，无需保存逐帧索引；从目标前至少 65,536 个解码输入样本处开始，并同时对齐容器块和重采样相位，重新初始化解码器／重采样器后丢弃预卷。DST 和无法安全定位的布局仍重放历史。

DSDIFF 未压缩流的时长根据 DSD 数据块字节数和声道数计算，不把标签/封面体积算进音频时长。已知长度文件检查 FRM8/DSF 声明范围，短读持续累积，真正的 STG_E_READFAULT 原样返回。

2026.10.23p1 增加 DSDIFF 顶层 ID3 和原生标签／附图编辑器，详情见下节。SACD ISO、原生 DSD、DoP 和自定义 PCM 输出参数不在本轮范围。

## 2026.10.23p1 修复和补全

### 解码与旧系统

- 修正后端 DST 不压缩帧的 DSD 字节排列，并核对该分支的精确帧长度。相同 DSD 数据的普通 DFF 与 DST 不压缩帧输出逐字节一致。
- DSF 非 seek 路径也从首部取得有效样本数；拒绝 demuxer 标记损坏的包。DST 使用 FRTE 时长对应的解码帧数核验结束位置，声明 48 帧而实际只有 24 帧不再正常结束。
- 输入倍率明确限制为 44.1／48 kHz 基频的 DSD64～1024，拒绝任意采样率落入 192 kHz 输出分支；DST 暂限 44.1 kHz 系列。
- 配置 YY-Thunks 的 DLL 入口及 x86 原入口别名，避免 XP 动态加载的 TLS 风险。
- 可定位流在部分读取后取消，重新开始时重建解码状态并恢复到已交付的精确 PCM 帧。非 seek 流若取消已消耗字节则保留失败，不伪装为可无损恢复。
- 删除不必要的 `avformat_find_stream_info` 预解码／封面探测；复用重采样工作缓冲，浮点输出使用整块复制。

### 标签和可靠保存

- 接受 `track`／`Tracknumber`、`album_artist`／`AlbumArtist`、`lyrics-*`／`Lyrics` 等别名，枚举使用宿主字段；ID3v2.4 多值文本以重复字段枚举，未修改的原始帧保留。
- 读取 DSF 尾部 ID3、DSDIFF 顶层和 PROP 内 ID3、DIIN 标题／艺术家；保留图片类型、描述和原始字节。
- 支持 ID3v2.3／v2.4 的 Unicode 文本、TXXX 自定义字段、COMM、USLT，以及 PNG／JPEG／WebP 封面。全局 unsynchronisation、扩展头、帧压缩／加密／复杂标志和混合版本标签暂不开放写入，继续 FFmpeg 可用的读取路径。
- 只使用宿主提供的 IStream。可编辑能力可由文件属性显示；真正修改仍要求可写流。网络流、归档只读流不自行重新打开物理文件。
- DSF 重写标签区域和文件长度／标签指针，保留音频及未知尾部；DSDIFF 保持所有原有音频和未知块的字节位置，较小标签复用原槽，扩大时追加顶层 ID3。旧标签槽／被修改的 DIIN 字段清零并改为 JUNK，避免删除后读回旧值，不破坏 DSTI 等未知偏移引用。
- 保留未改动 ID3 帧；保存前检查原容器头和元数据是否被外部改变。使用磁盘临时文件构造新内容并保存完整旧内容，64 KiB 缓冲复制；写入、截断、Commit 失败时恢复旧文件。介质持续失败时保留恢复副本并返回错误，不保证断电原子替换。
- 原版最后释放 Reader／Metadata／Thumbnail 后保存；独立 MetadataCommit 为终结操作，仅尝试一次，显式失败后 Release 不重试。没有修改旧虚表。

### 本地验收

私有测试位于 `rebuild/tests/dsd_complete_20261023`，不上传、不在 Action 执行、不进入发行包。

- 56 项解码／边界／短读／取消／精度／定位检查通过；参考 CLI 采用不同编译及 SIMD 配置，浮点比较容差为 2e-7，PCM24 量化误差不超过半个最低有效位。
- 另用容器长度完全正确、首个 DSTF 载荷比规定长度少／多一个字节的两个样本，确认不压缩帧长度错误返回失败。
- 80 项标签／封面／保存检查覆盖 DSF、DFF 顶层与 PROP 内标签、DST 容器、ID3v2.3／v2.4、三类故障回滚及最后释放保存；音频载荷和 DFF 音频位置不变。
- 长 DSF／DFF 定位到 7／3／9 秒分别读取 163,840 字节，PCM 与顺序解码对应位置逐字节一致。
- XP／Win7 实际执行六声道解码、长文件定位以及标签写入／删除／重读／失败恢复，通过；主机 Windows 11 承担现代系统验证。
- 最终 DLL 在 XP／Win7 的原版 5.7.9 和重建版中各执行一次实际播放，在 Win11 两个宿主中各播放 DSF／DFF；共 8 次检查均推进超过 3 秒，无错误窗口并正常退出。六声道 DSF 的 XP／Win7／Win11 PCM SHA-256 一致（`0d9d4a3cfb32ab3aa6fa3af17361115ad0dc9fbd4f76c3d91d16f5937e621751`）。这些是插件读取和宿主播放进度检查，没有采集声卡端数据。
- 解压对应源码附件到全新构建目录，使用附件内修正后的完整 FFmpeg 和 make 源码独立构建通过，未复用主构建的后端静态库；VC-LTL／YY-Thunks 使用本机已校验的固定版本。两个 PCM 对照和 9 项标签检查通过，插件源码／头文件／构建脚本逐字节与工作区一致。两个构建均通过 XP／Win7 导入表检查（5 个系统 DLL、151 个导入）。

### 保留的限制

本轮 DST 验证包括生成的不压缩帧、短帧和帧数不匹配，不冒充真实算术压缩 DST 的完整验收。尝试取得 FFmpeg FATE 的 `dst/dst-64fs44-2ch.dff` 时网络 TLS／连接超时，未取得有效文件。后端部分 DST 分段形式仍返回不支持，DSTC 的内容 CRC 尚未独立实现；设置解码器 CRC 检查标志不等于已覆盖该容器块。

非 seek DSF 可播放并检查截断，但尾部标签不可预读；当前 FFmpeg IFF 路径仍依赖定位，非 seek DSDIFF 未宣称支持。特殊声道重排、真实多声道 DAC 听音、多 GB 文件和全部高倍率真实录音仍需补充验收。PCM 固定输出 176.4／192 kHz；DSD 后端先生成 float32，再转 double 重采样，不宣称全程双精度。原生 DSD／DoP／ISO 属于单独的宿主功能扩展。

- 原版 5.7.9 / 重建版隔离目录启动、插件加载、无错误对话框及正常退出 smoke 通过。未把此测试当作原版宿主输出 PCM 逐样本对照。

### 原版宿主接口补验（2026-10-23）

用原版 5.7.9 EXE 和原 ttpcomm / ttpres，在隔离目录经私有转发探针调用发行插件的原始字节。原版实际调用 Open(3) → Format → Read：

- DSF：176400 Hz / 双声道 / float64 / WAVEFORMATEXTENSIBLE，398 次 Read，共 13,041,136 字节，播放进度 3611 ms。
- DFF：相同 PCM 输出格式，204 次 Read，共 13,368,816 字节，播放进度 3741 ms。
- 两者返回的浮点值均有限，峰值约 0.130042；没有 Reader 错误或宿主错误窗口，正常关闭。

因此原版能通过旧 Reader 接口接收 DSD 转换后的 PCM；不依赖新增 Probe/SourceInfo 或新版 ttpcomm 音频服务。原版识别 EXTENSIBLE IEEE_FLOAT（`004B0999`），64 位浮点可直接进入后续处理（`004B0D1A / 004B1375`）。这证明实际宿主读取，不只是 DLL 加载成功。

测试使用静音和原版默认 16 位输出设置，未采集声卡端数据。插件返回 float64 不等于原版以 64 位或原生 DSD 输出；启用 Winamp 音效时，原版 `004AC166` 仍转换为 PCM16。原生 DSD、DoP 和重建版新高精度处理模式不会因此自动出现在原版中。证据在私有 `rebuild/tests/wav_feedback_20261023/original-chain-results.json`。

初版验收时，DST、48 kHz 系列、更高倍率和 XP／Win7 GUI 播放尚未补验；后续结果以上方 2026.10.23p1 记录为准。非标准声道顺序和真实高采样率硬件仍需补样本验证；Win10 未独立运行，按用户要求由 Win11 承担现代系统验证。
